3. CONNAISSANCES TECHNIQUES
------------------------------------------------------------------

**Exiv2 0.28.6 API Changes (pour Phase 2 ou future ref)**
  Old (v2.0) :
    Exiv2::Image::AutoPtr image = Exiv2::ImageFactory::open(filename);
    catch (Exiv2::AnyError& e)
  New (0.28.6) :
    auto image = Exiv2::ImageFactory::open(filename);  (unique_ptr C++11)
    catch (Exiv2::Error& e)

**GTK3 Callback Signatures** (pour Phase 2)
  - Callbacks doivent accepter types generiques (GtkWidget *) pas types specifiques (RSCurveWidget *)
  - g_return_if_fail (void return) vs g_return_val_if_fail (non-void return, requiert valeur)
  - Draw callbacks doivent retourner gboolean (TRUE = handled, FALSE = propagate)

**RawStudio architecture** (ce qu'on herite)
  - librawstudio/ : librairie coeur (RAW I/O, plugins, metadata).
  - plugins/ : 20+ plugins (demosaic, denoise, colorspace, output, etc.).
  - src/ : application GUI (rawstudio binary).
  - plugins/load-rawspeed/ : plugin RAW decoder (RawSpeed C++ lib, bundled).
  - Autotools build system (configure.ac, Makefile.am templates).

**GConf Deprecated** (remplacement Phase 2)
  Old (GNOME 2/3 legacy) :
    GConf (daemon-based config store, API gconf_client_get, gconf_client_set)
  Modern (GNOME 3+) :
    Option 1 : GKeyFile (simple INI file, no daemon)
    Option 2 : dconf/GSettings (GNOME standard, requires daemon)
  Pour CaraStudio Phase 2 : GKeyFile probablement suffisant (simple, pas de dependencies exotiques).

**CTL integration** (futur Phase 3)
  CaraStudio ajoutera support des scripts CTL (comme ART).
  Architecture : RAW → demosaic → CTL tone/color → output.
  Necessites : lier CTL interpreter lib, scanner ~/.config/ART/ctlscripts/, UI pour selector scripts.
