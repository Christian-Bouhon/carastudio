4. CHANTIERS IDENTIFIES (warnings observes a l'usage)
------------------------------------------------------------------
[#1 BUG LOCALE FR] (vrai bug, PROCHAIN A TRAITER)
  "value '0,000000' of type 'gfloat' is invalid for property 'aperture'"
  -> virgule decimale (locale FR) au lieu de point. Le code parse/formate des
     floats avec la locale systeme ; GObject attend un point.
  Fix : g_ascii_strtod/g_ascii_dtostr au lieu de strtod/sprintf, ou
        setlocale(LC_NUMERIC,"C") pour les conversions numeriques.
  Cibler : lecture metadonnees EXIF (rs-exif.cc, rs-metadata.c) + conversions floats.

[#2 POPUP WAYLAND] (ergonomie)
  "gdk_wayland_window_handle_configure_popup: assertion 'impl->transient_for' failed"
  -> popup/menu sans parent transient. Wayland exige un parent. A nettoyer.

[#3 BASES DONNEES ANCIENNES] (limitation data, pas un bug)
  "Could not find unique camera: Make:'SONY' Model:'ILCE-7'"
  -> base camera/lens de 2011, ne connait pas les boitiers recents (Sony A7...).
  A moderniser : mettre a jour camera-database / profils.
