[BLOCKERS IDENTIFIES]
1. GConf (DEPRECATE, BYPASSÉ)
   - gconf-2.0 n'existe pas sur Fedora 44 (remplace par dconf/gsettings).
   - Contournement : supprime PKG_CHECK_MODULES(GCONF) de configure.ac et @GCONF_* de Makefile.am.
   - Solution Phase 2 : remplacer par GKeyFile (simple INI) ou dconf/GSettings (moderne).

2. Exiv2 API INCOMPATIBLE (MAIN BLOCKER)
   - RawStudio v2.0 utilise ancienne API Exiv2 (2010s) : Exiv2::Image::AutoPtr, Exiv2::AnyError.
   - Fedora 44 a Exiv2 moderne (0.27+) : API changee vers std::unique_ptr, exceptions differentes.
   - Symptome : errors compilation dans rs-exif.cc :
     'AutoPtr' is not a member of 'Exiv2::Image'
     'AnyError' in namespace 'Exiv2' does not name a type
   - Solution Phase 2 : porter rs-exif.cc vers nouvelle API Exiv2.

3. GTime DEPRECATED (WARNING, PAS BLOCKER)
   - Code utilise GTime (old GNOME 2 type), deprecie en faveur GDateTime.
   - Compile mais genere warnings : 'GTime' is deprecated.
   - Solution Phase 2 : remplacer GTime par GDateTime (medium effort).

[MODIFICATIONS APPORTEES A LA SOURCE]
1. Edite configure.ac : supprime ligne PKG_CHECK_MODULES(GCONF, ...).
2. Edite librawstudio/Makefile.am et src/Makefile.am : supprime @GCONF_CFLAGS@ et @GCONF_LIBS@.
3. Regenere : ./autogen.sh, ./configure, make.

**Exiv2 modern API (pour Phase 2)**
  Old (v2.0) :
    Exiv2::Image::AutoPtr image = Exiv2::ImageFactory::open(filename);
    Exiv2::AnyError& e
  New (0.27+) :
    auto image = Exiv2::ImageFactory::open(filename);  (unique_ptr)
    Exiv2::Error& e  (Exception class changed)
  Fix : Mettre a jour rs-exif.cc pour utiliser nouvelle API (grep -n "AutoPtr\|AnyError").

**CTL integration (futur Phase 3)**
  CaraStudio ajoutera support des scripts CTL (comme ART).
  Architecture : RAW → demosaic → CTL tone/color → output.
