# CaraStudio

A lightweight, modern RAW processor with CTL scripting support. Fork of RawStudio enhanced for Linux with advanced color processing and extensibility.

## Features (Planned)

- RAW image development and batch processing
- CTL scripting support for tone curves and color grading
- Modern GTK+ 4 interface
- Multi-core processing
- Color management with LittleCMS

## About This Fork

CaraStudio is a fork of [RawStudio](https://rawstudio.org/) (originally by Anders Brander and Anders Kvist), modernized and enhanced with:
- CTL (Color Transformation Language) scripting integration
- Updated to GTK+ 4
- Contemporary design and branding
- Focus on script-based extensibility
